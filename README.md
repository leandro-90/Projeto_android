# 📱 Projeto História do Android

Um site informativo e educacional desenvolvido para contar a história e a evolução do sistema operacional Android, desde a criação do mascote Bugdroid até as versões atuais.

🔗 **Acesse o site:** [leandro-90.github.io/Projeto_android](https://leandro-90.github.io/Projeto_android/)

---

## 📌 Sobre o Projeto

O objetivo deste projeto é consolidar conceitos fundamentais de desenvolvimento web front-end através da criação de uma página visualmente agradável, responsiva e rica em conteúdo histórico sobre o ecossistema Android.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout responsivo e variáveis CSS para paleta de cores.

---

## 🎨 Funcionalidades e Destaques

- **Design Responsivo:** Adaptável a telas de smartphones, tablets e desktops.
- **Tipografia Customizada:** Utilização de fontes personalizadas para destacar títulos e corpo de texto.
- **Conteúdo Didático:** Curiosidades sobre a nomenclatura das versões do Android e a origem do mascote.
- **Navegação Simples:** Layout limpo e focado na experiência de leitura do usuário.
